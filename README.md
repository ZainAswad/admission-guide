# الوزني لتجارة الكهربائيات والإنارة الحديثة — متجر إلكتروني

> **ضوء يصنع الفرق**

متجر إلكتروني متكامل بالعربية (RTL) لمحل الوزني للكهربائيات في كربلاء المقدسة.
مبني بـ HTML/CSS/JavaScript خالص — **بدون أي مكتبات خارجية وبدون خطوة بناء (build)** — لذلك يعمل بسرعة عالية جداً ويُنشر على Vercel مباشرة.

---

## المحتويات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الموقع (الهيدر، القائمة الجانبية، الفوتر، النوافذ المنبثقة) |
| `assets/css/styles.css` | نظام التصميم كاملاً (Material Design · SaaS) |
| `assets/js/data.js` | **ملف البيانات — عدّل هذا الملف لإضافة المنتجات والأقسام** |
| `assets/js/icons.js` | أيقونات الواجهة + 36 رسمة توضيحية للمنتجات (SVG داخلي) |
| `assets/js/store.js` | السلة والمفضلة والطلبات والتخزين المحلي |
| `assets/js/app.js` | التوجيه (Router) وواجهات الصفحات |
| `vercel.json` | إعدادات النشر والتخزين المؤقت |
| `admission-guide.html` | الملف القديم الذي كان في المستودع (محفوظ كما هو) |

## الربط مع GitHub و Vercel

1. ادفع الفرع إلى GitHub (تم ذلك مسبقاً).
2. من [vercel.com/new](https://vercel.com/new) اختر **Import Git Repository** وحدّد هذا المستودع.
3. في إعدادات المشروع:
   - **Framework Preset:** `Other`
   - **Build Command:** اتركه فارغاً
   - **Output Directory:** اتركه فارغاً (الجذر `.`)
4. اضغط **Deploy** — الموقع يصبح جاهزاً خلال ثوانٍ.
5. لاحقاً يمكن ربط نطاق خاص من **Settings → Domains**.

كل دفعة (push) جديدة إلى الفرع تُنشر تلقائياً.

## كيف تضيف منتجاً؟

افتح `assets/js/data.js` وأضف عنصراً إلى مصفوفة `PRODUCTS`:

```js
{ id:'LT-999', name:'اسم المنتج', brand:'العلامة', price:12000, old:15000,
  icon:'bulb', badge:'new', unit:'حبة',
  cats:['lighting/bulbs','lighting/ceiling'],   // يمكن وضعه في أكثر من قسم
  desc:'وصف مختصر يظهر في صفحة المنتج.',
  specs:['مواصفة أولى','مواصفة ثانية'] },
```

**الحقول:**

- `id` — رقم فريد للمادة (يظهر للزبون وفي الطلب).
- `price` — السعر بالدينار العراقي. `old` (اختياري) السعر قبل التخفيض ويُحتسب منه شارة الخصم تلقائياً.
- `cats` — قائمة الأقسام الفرعية بصيغة `"القسم الرئيسي/القسم الفرعي"`. **ضع أكثر من قسم إذا كانت المادة تخدم أكثر من استخدام** (الأقسام متداخلة عن قصد).
- `badge` — `'hot'` (الأكثر طلباً) أو `'new'` (جديد) أو `'sale'` (تخفيض) أو اتركه.
- `icon` — اسم الرسمة التوضيحية. الأسماء المتاحة موجودة في `assets/js/icons.js` داخل الكائن `ART`.
- `image` — (اختياري) مسار صورة حقيقية، مثل `'assets/img/otg-45a.jpg'`. إذا وُجدت تحلّ محل الرسمة التوضيحية.

### إضافة صور حقيقية للمنتجات

ضع الصورة في `assets/img/` ثم أضف `image:'assets/img/اسم-الصورة.jpg'` إلى المنتج.
يُفضّل صور مربعة بمقاس 800×800 بكسل وبحجم أقل من 200 كيلوبايت.

## كيف تضيف قسماً جديداً؟

في نفس الملف، أضف إلى `CATEGORIES`:

```js
{ id: 'newcat', name: 'اسم القسم', icon: 'socket', blurb: 'وصف قصير',
  subs: [ { id:'sub1', name:'قسم فرعي', icon:'bulb' } ] }
```

القسم يظهر تلقائياً في: الشريط العلوي، القائمة الجانبية، صفحة الأقسام، والفوتر.

## آلية تسجيل طلبات الزبائن

لم تكن هناك آلية سابقة، فتم بناء الآتي:

1. الزبون يملأ نموذج **إتمام الطلب** (الاسم، الهاتف، المحافظة، العنوان، طريقة الاستلام والدفع).
2. يُولَّد **رقم طلب فريد** بصيغة `WZ-YYMMDD-###`.
3. يُحفظ الطلب في متصفح الزبون (`localStorage`) ويظهر في صفحة **طلباتي**.
4. تظهر صفحة تأكيد فيها زر **«إرسال الطلب عبر واتساب»** — يفتح واتساب برسالة جاهزة تحتوي كل تفاصيل الطلب والمواد والأسعار، فتصل إلى رقم المحل مباشرة.
5. يوجد أيضاً زر **نسخ تفاصيل الطلب** كبديل.

### (اختياري) حفظ الطلبات في قاعدة بيانات

في `assets/js/data.js` ضمن `SITE.orders` ضع رابطاً في الحقل `webhook`:

```js
webhook: 'https://formspree.io/f/xxxxxxx'
```

عندها يُرسَل كل طلب تلقائياً كـ JSON إلى ذلك الرابط بالإضافة إلى الواتساب.
تصلح معه خدمات مثل Formspree أو Google Apps Script أو أي Serverless Function على Vercel.

## تعديل بيانات المحل

كل شيء في أعلى `assets/js/data.js` داخل الكائن `SITE`:

- `phones` — أرقام الهواتف (أضف أرقاماً أخرى بنفس الصيغة).
- `whatsapp` — رقم استقبال الطلبات.
- `address` و `geo` — العنوان وإحداثيات الخريطة (**عدّل `lat` و `lng` لتطابق موقع المحل بدقة**).
- `social` — روابط فيسبوك/انستغرام/تيك توك/تيليكرام (اتركها فارغة لتختفي من الموقع).
- `hours` — أوقات الدوام.
- `orders` — أجور التوصيل داخل/خارج كربلاء وحد التوصيل المجاني.
- `BRANDS` — أسماء العلامات التجارية التي تظهر في الشريط المتحرك.

## المزايا المنفّذة

- **بحث فوري** مع اقتراحات ودعم تطبيع النص العربي (الهمزات والتاء المربوطة والألف المقصورة).
- **سلة تسوق** كاملة مع تعديل الكميات وشريط تقدّم للتوصيل المجاني وحساب التوفير.
- **قائمة مفضلة** محفوظة على الجهاز.
- **عرض سريع** للمنتج في نافذة منبثقة + صفحة منتج مستقلة قابلة للمشاركة.
- **فلترة حسب العلامة التجارية** وترتيب حسب السعر/التخفيض/الاسم.
- **Bento grid متغيّر** في الصفحة الرئيسية يعرض منتجات وأقسام تتبدّل تلقائياً.
- **خريطة الموقع** وأرقام التواصل وأوقات الدوام في صفحة التواصل.
- تصميم متجاوب بالكامل، ودعم `prefers-reduced-motion`، وتنقّل بلوحة المفاتيح.
